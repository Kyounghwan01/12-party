# 연말 파티 팀 게임 기획안

100명 규모 연말 파티에서 레드·그린 두 팀이 겨루는 게임을 진행한다. 회사가 PO(Project Owner) 체제를 처음 도입하면서 핵심 역량으로 **소통**을 정했고, 이 행사도 "소통을 잘하자"라는 메시지를 전하는 것이 목적이다. 게임과 리워드는 이기는 것보다 **말하고 맞추는 경험**이 남도록 설계한다.

## 한눈에 보기

**총 72분** (시작 전 입장 15분 별도): 오프닝 → 아이스브레이킹 → 피자파티 with 게임 4종 → 최종 발표 → 부사장님 발표 및 격려 → 정리. 시간은 모두 제안이다.

| 시간         | 단계                  | 내용                                                                | 참여                    |
| ------------ | --------------------- | ------------------------------------------------------------------- | ----------------------- |
| 시작 전 15분 | 입장                  | 조 번호 스티커 배부, 조 구역에 자리 잡기                            | 전원                    |
| 0–8분       | 오프닝                | 환영·소통 메시지·진행 안내 5분, 조별 인사와 조 내 번호 정하기 3분 | 전원                    |
| 8–13분      | 아이스브레이킹        | 조 대항 스피드 게임 3번, 이긴 조는 프리미엄 피자 선점               | 전원 (조별)             |
| 13–14분     | 리워드 소개           | 팀전 리워드(우승 팀 한정선) 소개                                    | 전원                    |
| 14분         | 피자 배분 시작        | 게임 시작과 함께 조별로 전달, 먹으면서 게임에 참여                  | 전원                    |
| 14–21분     | 참참참                | 3판 2선승, 레드 대 그린 5경기                                       | 각 조 1번 (10명)        |
| 21–33분     | 숫자 맞추기           | 레드·그린 조가 번갈아 공격                                         | 각 조 3~6번 (40명)      |
| 33–43분     | 몸으로 말해요         | 2번이 몸으로 표현하고 자기 조가 맞히기                              | 각 조 2번 (10명) + 조원 |
| 43–55분     | OX 퀴즈               | 각자 판단해 O/X 이동                                                | 나머지 전원 (약 40명)   |
| 55–57분     | 최종 발표             | 네 게임 합계로 우승 팀 발표, 한정선 전달                            | 전원                    |
| 57–67분     | 부사장님 발표 및 격려 | 부사장님 발표와 격려 말씀                                           | 전원                    |
| 67–72분     | 정리                  | 팀 구분 없이 다 같이 정리                                           | 전원                    |

| 항목        | 내용                                                                               |
| ----------- | ---------------------------------------------------------------------------------- |
| 인원        | 약 100명 (레드 50 · 그린 50, 옷 색으로 구분)                                      |

| 컨셉        | 소통                                                                               |
| 리워드 제약 | 개인 상품 불가. 실제 부서 팀원이 레드·그린에 섞여 있어 색깔 팀 단위 회식비도 곤란 |

## 팀·조 구성

점수는 레드 vs 그린으로 겨루고, 조별 인사와 게임 참가자 선정은 10명 안팎의 조에서 한다.

- **구성**: 레드 1~5조, 그린 1~5조 (스티커와 번호판은 팀 색으로 구분)
- **배정**: 입장 순서대로 조 번호 스티커를 순환 배부한다 (레드와 그린 각각 1→2→3→4→5→1…). 연달아 입장한 지인이 서로 다른 조로 흩어지고, 같은 색 안에서 조별 배정 인원 차이는 최대 1명이다.
- **자리**: 입장하면 구역 번호판을 보고 자기 조 구역에 모인다. 피자도 이곳에서 먹는다.
- **게임 참가자**: 조원이 다 모이면 조 안에서 임의로 1번부터 번호를 매긴다. 이 번호로 참가할 게임이 정해진다.

| 조 내 번호 | 참가 게임     | 전체 인원 |
| ---------- | ------------- | --------- |
| 1번        | 참참참        | 10명      |
| 2번        | 몸으로 말해요 | 10명      |
| 3~6번      | 숫자 맞추기   | 40명      |
| 7번 이후   | OX 퀴즈       | 약 40명   |

- **점수**: 레드·그린 점수만 집계하고 조별 점수는 내지 않는다.
- **인원이 다를 때**: OX 퀴즈는 정답자 수 대신 비율(정답자 ÷ 팀 참가 인원)로 판정한다.

## 진행 흐름

### 0. 입장 (시작 전 15분)

입구에서 색깔별로 조 번호 스티커를 받고 자기 조 구역에 자리 잡는다.

### 1. 오프닝 (0–8분)

환영 인사 후 PO 체제와 소통 메시지를 짧게 소개하고 전체 순서를 안내한다 (5분). 조별로 이름과 올해 한마디를 나누며 인사하고 조 내 번호를 정한다 (3분). 게임 룰은 각 게임 직전에 설명한다.

### 2. 아이스브레이킹 게임 (8–14분)

조별 인사에 이어 10개 조가 겨루는 **스피드 게임을 3번** 한다 (5분). 조원끼리 바로 말을 트게 하는 것이 목적이다.

- 사회자 전화번호 뒷자리 빨리 맞히기
- "강낭콩땅콩찹쌀떡"처럼 어려운 문장을 빨리 타이핑해 사회자에게 문자 보내기
- 나머지 1개는 같은 방식의 스피드 게임으로 정한다

라운드마다 가장 빠른 조가 이기고, 이긴 조는 **프리미엄 피자를 먼저 고를 기회**를 얻는다. 조 단위 보상이며 레드·그린 팀 점수에는 넣지 않는다. 끝나면 팀전 리워드(우승 팀 한정선)를 소개한다 (1분).

### 3. 피자파티 with 게임 (14–55분)

게임 시작과 함께 피자를 조 구역으로 전달하기 시작한다. 아이스브레이킹에서 이긴 조가 프리미엄 피자를 먼저 고른다. 별도 식사 시간은 없고, 자기 차례가 아닌 사람은 먹으면서 응원한다. 한 줄 배식 대신 도우미가 조별로 전달한다.

게임은 참참참 → 숫자 맞추기 → 몸으로 말해요 → OX 퀴즈 순서로 하며, 조 내 번호에 따라 한 사람이 한 게임에 참가한다. 아래 시간에는 룰 설명과 집계가 포함된다.

### 4. 최종 발표 (55–57분)

OX 퀴즈가 끝나면 전원 조 구역으로 돌아온다. 네 게임 점수를 더해 최종 우승 팀을 발표하고 한정선을 전달한다. 동점이면 OX 예비 문제로 가린다.

### 5. 부사장님 발표 및 격려 (57–67분)

최종 발표에 이어 부사장님 발표와 격려 말씀을 듣는다 (10분).

### 6. 정리 (67–72분)

팀 구분 없이 다 같이 정리한다. 각자 접시와 컵을 조별 봉투에 담고, 조별로 피자 박스·쓰레기 봉투·테이블·바닥·게임 소품을 치운다.

음악을 틀어 가볍게 진행한다. 몸이 불편한 사람은 분리수거 안내처럼 가벼운 역할을 맡는다.

### 시간이 밀릴 때

OX 퀴즈는 7번 문제를 뺀다. 숫자 맞추기는 상의 시간을 줄인다 (모든 조가 한 번씩 참여하도록 10번은 유지). 정리는 유지하고, 전체 종료가 조금 늦어지는 것은 괜찮다.

## 리워드

개인 상품 없이 **간식**으로만 구성하고, 모두 행사장 안에서 끝낸다. 피자 양은 모두 같고, 프리미엄 피자를 고르는 순서만 다르다.

| 시점              | 기준                     | 리워드                  |
| ----------------- | ------------------------ | ----------------------- |
| 아이스브레이킹 후 | 라운드별 1위 조 (3개 조) | 프리미엄 피자 선점      |
| 최종 발표 때      | 최종 점수 1위            | 한정선 (팀 인원분 50개) |

## 게임 상세 (추후 보완)

세부 룰과 배점은 현재 초안이며 나중에 확정한다.

### 참참참 (7분, 각 조 1번)

- 레드 n조 1번과 그린 n조 1번이 앞에 나와 겨룬다. 모두 5경기.
- **3판 2선승**. 공격자가 손가락 봉으로 방향을 가리키고, 수비자의 고개가 같은 방향이면 공격자가, 다르면 수비자가 그 판을 이긴다 (제안). 첫 공격은 가위바위보로 정하고 판마다 공수를 바꾼다.
- 경기를 이긴 사람의 팀이 1점을 얻는다.
- 시간: 룰 설명 1분 + 5경기 × 1분 + 여유 1분

### 숫자 맞추기 (12분, 각 조 3~6번)

- 조 구역에서 각 조 3~6번 4명이 참가한다. 조 대 조로 공격을 이어 가며, 10번이면 모든 조가 **공격 1번, 수비 1번**을 한다.

| 순서 | 공격 → 수비         | 순서 | 공격 → 수비         |
| ---- | -------------------- | ---- | -------------------- |
| 1    | 레드 1조 → 그린 1조 | 2    | 그린 1조 → 레드 2조 |
| 3    | 레드 2조 → 그린 2조 | 4    | 그린 2조 → 레드 3조 |
| 5    | 레드 3조 → 그린 3조 | 6    | 그린 3조 → 레드 4조 |
| 7    | 레드 4조 → 그린 4조 | 8    | 그린 4조 → 레드 5조 |
| 9    | 레드 5조 → 그린 5조 | 10   | 그린 5조 → 레드 1조 |

- 공격 조는 외칠 숫자(0~4)를, 수비 조는 일어설 인원을 **동시에 비밀 상의**한다. 신호에 맞춰 공격 조가 숫자를 외치는 순간 수비 조 4명도 앉거나 선다.
- 선 인원이 외친 숫자와 **같으면 공격 조의 팀이 1점**, 다르면 방어 성공으로 점수가 없다 (제안).
- 시간: 룰 설명 1분 30초 + 공격 10번 × 1분 + 여유 30초. 공격 1번은 상의 20초 → 동시에 외치고 앉기/서기 → 결과 발표 순서다.
- 보완할 점: 4명 기준 판정 범위 확정(정확히 일치 또는 ±1), 바닥에 앉기 어려우면 손 들기/내리기로 대체

### 몸으로 말해요 (10분, 각 조 2번)

- 각 조 2번이 앞에 나와 스케치북의 제시어를 말 없이 몸으로 표현하고, **자기 조**가 맞힌다.
- 조마다 45초 동안 맞힌 개수를 센다. 통과는 자유.
- 레드 n조와 그린 n조를 비교해 더 많이 맞힌 조의 팀이 1점을 얻는다. 같으면 양 팀 모두 1점 (제안).
- 시간: 룰 설명 1분 30초 + 10개 조 × 45초 + 여유 1분
- 보완할 점: 제시어 난이도와 개수, 스케치북을 넘겨 줄 도우미

### OX 퀴즈 (12분, 각 조 7번 이후)

- 본 문제 7개 + 동점용 예비 1개. 가운데 줄을 기준으로 O/X 구역으로 이동한다.
- 상의 없이 **각자 판단**한다. 문제 사이에 조 구역으로 돌아가지 않는다. 탈락자는 없다.

| 12분 배분                      | 시간     | 누적      |
| ------------------------------ | -------- | --------- |
| 룰 설명                        | 1분 30초 | 1분 30초  |
| 본 문제 7개 × 75초            | 8분 45초 | 10분 15초 |
| 예비 문제 1개 (동점일 때 사용) | 1분 15초 | 11분 30초 |
| 여유                           | 30초     | 12분      |

| 문제당 75초                   | 시간 | 누적 |
| ----------------------------- | ---- | ---- |
| 문제 읽기                     | 15초 | 15초 |
| 이동                          | 10초 | 25초 |
| 카운트다운 (끝나면 이동 금지) | 5초  | 30초 |
| 인원 집계                     | 25초 | 55초 |
| 정답·점수 발표               | 20초 | 75초 |

- 집계는 도우미가 레드·그린을 1명씩 맡아 팀별로 적은 쪽만 세고 팀 참가 인원에서 뺀다. 정답 공개 전에 센다.
- 라운드마다 정답자 비율이 높은 팀이 1점을 얻는다. 비율이 같으면 양 팀 모두 1점.
- 회사·동료·PO 체제 관련 문제를 섞는다.
- 예비 문제는 네 게임 합계 점수가 같을 때 쓴다.

- [ ] 행사 날짜·시작 시간·장소
- [ ] 간식 1안과 2안 중 선택
- [ ] 아이스브레이킹 세 번째 게임, 판정 방법(동시 도착·오타 처리)
- [ ] 부사장님 발표 및 격려 시간과 필요한 장비(슬라이드 여부)
- [ ] 게임별 세부 룰과 시간 배분
- [ ] 점수 배점과 동점 규칙
- [ ] 진행용 PPT (전체 순서, 게임별 룰 설명, 점수판)

**준비할 것**

- [ ] MC 1명, 점수·인원 집계와 피자 전달 도우미 2명 이상
- [ ] 게임 물품 주문 (라벨, 스케치북, 손가락 봉)
- [ ] 몸으로 말해요 제시어, OX 퀴즈 8개(예비 포함) 출제
- [ ] 대형 화면과 MC용 노트북
- [ ] 조 번호 스티커 100장, 구역 번호판 10개, 시작 전 15분 입장·배부 동선
- [ ] 조 구역, 앞쪽 게임 공간, O/X 구역, 피자 전달 동선 배치도
- [ ] 한정선 50개 + 여유분 주문
- [ ] 프리미엄 피자 종류와 수량, 문자를 받을 사회자 휴대폰
- [ ] 피자(또는 피자빵)·콜라 수량 확정, 알레르기·채식 확인
- [ ] 마이크, 문제 슬라이드, 정리용 음악
- [ ] 조별 쓰레기 봉투, 물티슈, 청소 도구
- [ ] 항목별 담당자와 마감일
