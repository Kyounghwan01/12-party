# 연말 파티 팀 게임 기획안

2026-11-25 · 작성: Joshua

100명 규모 연말 파티에서 레드·그린 두 팀이 겨루는 게임을 진행한다. 회사가 PO(Project Owner) 체제를 처음 도입하면서 핵심 역량으로 **소통**을 정했고, 이 행사도 "소통을 잘하자"라는 메시지를 전하는 것이 목적이다. 게임과 리워드는 이기는 것보다 **말하고 맞추는 경험**이 남도록 설계한다.

## 한눈에 보기

**총 82분** (시작 전 입장 15분 별도): 메인 게임 → 조별 식사 → 작은 게임 → 정리

| 시간 | 단계 | 내용 | 역할 | 리워드 |
| --- | --- | --- | --- | --- |
| 시작 전 15분 | 입장 | 조 번호 스티커 배부, 조 구역에 자리 잡기 | | |
| 0–7분 | 오프닝 | 환영·소통 메시지·진행 안내 5분 + 조별 인사 2분 | 만나기 | |
| 7–19분 | OX 퀴즈 | 각자 판단해 O/X 이동 | 혼자 판단하기 | |
| 19–37분 | 숫자 맞추기 | OX가 끝난 자리에서 바로 진행 | 함께 맞추기 | |
| 37–47분 | 중간 발표·배식 | 조 구역으로 이동, 중간 점수 발표, 피자 배식 | | 앞선 팀 **피자 우선 배식 + 디저트** |
| 47–67분 | 조별 식사 | 자유 대화 20분, 62분부터 QR 접속 안내 | 서로 알기 | |
| 67–77분 | 작은 게임 | 모바일 실시간 퀴즈, 결과와 우승 발표 | 서로를 맞히기 | 이긴 팀 **뒷정리 면제권**, 최종 우승 팀 **"올해의 소통 팀"** 선포 |
| 77–82분 | 정리 | 전원 자기 자리 정리, 진 팀 공용 정리 | 함께 끝내기 | |

혼자 판단하는 게임에서 시작해 함께 맞추고 서로를 알아가는 순서로, "혼자보다 함께"라는 소통 메시지를 전한다.

## 행사 전제

| 항목 | 내용 |
| --- | --- |
| 인원 | 약 100명 (레드 50 · 그린 50, 옷 색으로 구분) |
| 장소 | 좁은 편. 줄다리기·뛰는 게임 불가, O/X 구역 이동 정도는 가능 |
| 컨셉 | 소통 |
| 리워드 제약 | 개인 상품 불가. 실제 부서 팀원이 레드·그린에 섞여 있어 색깔 팀 단위 회식비도 곤란 |

## 팀·조 구성

점수는 레드 vs 그린으로 겨루고, 조별 인사와 식사는 10명 안팎의 조에서 한다.

- **구성**: 레드 1~5조, 그린 6~10조
- **배정**: 입장 순서대로 조 번호 스티커를 순환 배부한다 (레드 1→2→3→4→5→1…, 그린 6→7→8→9→10→6…). 연달아 입장한 지인이 서로 다른 조로 흩어지고, 같은 색 안에서 조별 배정 인원 차이는 최대 1명이다.
- **자리**: 입장하면 구역 번호판을 보고 자기 조 구역에 모인다. 게임이 끝나면 배식 때 돌아와 이곳에서 식사한다.
- **점수**: 레드·그린 점수만 집계하고 조별 점수는 내지 않는다.
- **인원이 다를 때**: OX 퀴즈는 정답자 수 대신 비율(정답자 ÷ 팀 인원)로 판정한다.

## 진행 흐름

### 0. 입장 (시작 전 15분)

입구에서 색깔별로 조 번호 스티커를 받고 자기 조 구역에 자리 잡는다.

### 1. 오프닝 (0–7분)

환영 인사 후 PO 체제와 소통 메시지를 짧게 소개하고 전체 순서를 안내한다 (5분). 이어서 조별로 이름과 올해 한마디를 나누며 인사한다 (2분). 게임 룰은 각 게임 직전에 설명한다.

> "오늘 처음 이야기하는 분과 인사해 보세요."

### 2. 메인 게임 (7–37분)

움직임이 필요한 게임은 모두 식사 전에 끝낸다. 아래 시간에는 룰 설명과 집계가 포함된다.

- **OX 퀴즈 (7–19분)**: 본 문제 7개. 각자 판단해 O/X 구역으로 이동한다. 정답자 비율이 높은 팀이 득점하며, 탈락자는 없다.
- **숫자 맞추기 (19–37분)**: 조 구역으로 돌아가지 않고 **그 자리에서 바로** 시작한다. 공격팀이 숫자를 외치면 수비팀이 주변의 같은 색 사람과 상의해 그 숫자만큼 일어선다.

> OX → 숫자 맞추기: "이번에는 혼자 골랐습니다. 다음은 옆 사람과 이야기하지 않으면 이길 수 없습니다."

### 3. 중간 발표와 배식 (37–47분)

전원 조 구역으로 이동한다. 중간 점수에서 앞선 팀의 조 구역부터 피자를 전달하고, 앞선 팀에는 디저트를 함께 준다. 피자는 순서만 다르고 양은 같다. 디저트는 낱개 포장으로 조별 상자에 나눠 두었다가 피자와 같이 전달한다. 한 줄 배식 대신 조별로 전달해 10분 안에 끝낸다.

배식 때 마지막 승부를 예고해 식사 중 이탈을 막는다.

> "식사 후 마지막 게임이 남아 있습니다. 최종 승부와 특별한 혜택이 준비되어 있으니 끝까지 함께해 주세요!"

### 4. 조별 식사 (47–67분)

> "이제 편하게 서로를 알아보세요."

20분간 MC 개입 없이 조 구역에서 자유롭게 먹고 이야기한다. 대형 화면에 가벼운 대화 주제 1개를 띄운다. **62분부터** 접속을 안내하고, 참가자는 QR로 퀴즈에 접속해 팀을 고르고 이름을 입력해 입장한 뒤, 다수결 문제용 사전 설문에 답한다.

### 5. 작은 게임 (67–77분)

> "우리가 서로를 얼마나 아는지 확인해 보겠습니다."

각자 휴대폰 웹으로 접속해 **실시간 퀴즈**를 푼다. 빨리 맞힐수록 점수가 높고, 대형 화면에 팀 점수와 개인 순위를 띄운다. 시작 전에 리워드를 알린다.

> "이긴 팀은 뒷정리 면제! 진 팀은 마지막 팀워크를 보여주세요!"

### 6. 정리 (77–82분)

> "마지막까지 함께 정리하고 마치겠습니다."

정리가 끝나면 행사를 마친다.

| 구분 | 할 일 |
| --- | --- |
| 전원 | 자기 접시와 컵을 조별 봉투에 담기 |
| 이긴 팀 | 자기 자리 정리 후 면제 |
| 진 팀 | 5개 조가 공용 정리를 하나씩 분담: 피자 박스 / 쓰레기 봉투 / 테이블 / 바닥 / 게임 소품 |

음악을 틀어 가볍게 진행한다. 몸이 불편한 사람은 분리수거 안내처럼 가벼운 역할을 맡는다.

### 시간이 밀릴 때

숫자 맞추기와 모바일 퀴즈의 라운드 수를 줄인다. 식사 20분과 정리는 유지하고, 전체 종료가 조금 늦어지는 것은 괜찮다.

## 리워드

개인 상품 없이 **음식 + 면제권 + 명예**로 구성하고, 모두 행사장 안에서 끝낸다.

| 시점 | 기준 | 리워드 | 의도 |
| --- | --- | --- | --- |
| 메인 게임 후 | 중간 점수 1위 | 피자 우선 배식 + 디저트 | 피자 양은 같고 디저트만 추가라 박탈감이 적음 |
| 작은 게임 후 | 작은 게임 승리 | 뒷정리 면제권 | 메인 게임에서 진 팀도 다시 노릴 수 있음 |
| 퀴즈 결과 발표 때 | 최종 점수 1위 | "올해의 소통 팀" 선포, 소품 트로피 | 소통 메시지를 남김 |

모바일 퀴즈 개인 1위는 상품 없이 "오늘의 퀴즈왕"으로 호명하고 박수를 보낸다.

디저트는 메인 게임 리워드로만 쓰고, 게임 사이 간식은 제공하지 않는다.

## 게임 상세 (추후 보완)

전체 흐름을 먼저 정하고 세부 룰은 나중에 확정한다. 아래는 현재 초안이다.

### 메인 게임

**OX 퀴즈**

- 본 문제 7개 + 동점용 예비 1개. 가운데 줄을 기준으로 O/X 구역으로 이동한다.
- 조별 상의 없이 **각자 판단**한다. 문제 사이에 조 구역으로 돌아가지 않는다.
- 시간 배분은 아래 표를 따른다. 밀리면 7번 문제를 뺀다.

| 12분 배분 | 시간 | 누적 |
| --- | --- | --- |
| 룰 설명 | 1분 30초 | 1분 30초 |
| 본 문제 7개 × 75초 | 8분 45초 | 10분 15초 |
| 예비 문제 1개 (동점일 때 숫자 게임 후 사용) | 1분 15초 | 11분 30초 |
| 여유 | 30초 | 12분 |

| 문제당 75초 | 시간 | 누적 |
| --- | --- | --- |
| 문제 읽기 | 15초 | 15초 |
| 이동 | 10초 | 25초 |
| 카운트다운 (끝나면 이동 금지) | 5초 | 30초 |
| 인원 집계 | 25초 | 55초 |
| 정답·점수 발표 | 20초 | 75초 |

- 집계는 도우미가 레드·그린을 1명씩 맡아 팀별로 적은 쪽만 세고 전체 인원에서 뺀다. 정답 공개 전에 센다.
- 라운드마다 정답자 비율이 높은 팀이 1점을 얻는다. 비율이 같으면 양 팀 모두 1점.
- 회사·동료·PO 체제 관련 문제를 섞는다.
- 예비 문제는 숫자 게임까지 끝난 뒤 중간 점수가 같을 때 쓴다.
- 보완할 점: 한쪽에 100명이 몰려도 되는지, 이동·집계 시간이 맞는지 현장 리허설로 확인

**숫자 맞추기 (앉기/서기)**

- OX가 끝난 자리에서 그대로 진행한다. 공격팀은 전원 앉고, 수비팀만 앉거나 선다.
- 공격팀은 상대 팀 인원의 20~80% 범위에서 숫자를 외친다 (50명 기준 10~40).
- 수비팀은 자리를 옮기지 않고 **주변의 같은 색 사람과 10초** 상의한 뒤, 신호에 맞춰 동시에 앉거나 선다. 조 번호를 활용한 약속도 허용한다.
- 선 인원이 숫자의 ±3 안이면 수비팀 승리, 벗어나면 공격팀 득점. 첫 라운드는 ±5로 시작한다.
- 공격은 양 팀이 번갈아 같은 횟수로 한다.
- 집계는 서 있는 사람만 센다.
- 보완할 점: 18분 세부 배분과 라운드 수, 수비 성공 시 득점 여부, 인원이 다를 때 오차 보정, 바닥에 앉기 어려우면 손 들기/내리기로 대체

### 작은 게임: 모바일 실시간 퀴즈

**진행 방식**

1. 식사 마지막 5분에 QR로 접속해 레드·그린 팀을 고르고 이름을 입력한 뒤 "게임입장"을 누른다.
2. MC가 시작하면 전원 휴대폰에 문제가 동시에 표시된다.
3. 15초 안에 답을 고른다. 빨리 맞힐수록 점수가 높다.
4. 정답과 순위를 공개하고 다음 문제로 넘어간다.

| 10분 배분 | 시간 | 누적 |
| --- | --- | --- |
| 룰 설명, 접속 확인 | 2분 | 2분 |
| 문제 8개 × 45초 | 6분 | 8분 |
| 퀴즈 결과와 뒷정리 팀, 최종 우승 팀 발표 | 1분 | 9분 |
| 여유 | 1분 | 10분 |

| 문제당 45초 | 시간 | 누적 |
| --- | --- | --- |
| 문제 읽기 | 5초 | 5초 |
| 답변 | 15초 | 20초 |
| 정답 공개 | 10초 | 30초 |
| 순위 공개 | 15초 | 45초 |

**점수와 순위 (제안)**

- 정답 500점 + 속도 최대 500점, 오답·무응답 0점
- 퀴즈 승부는 **팀 평균 점수**(팀 총점 ÷ 팀 전체 참가자 수)로 가린다.
- 개인 순위는 TOP 5만 공개한다.
- 퀴즈 점수는 승패를 가리는 데만 쓰고, 최종 점수에는 이긴 팀에 정해진 점수(2점 제안)를 더한다.

**화면**

| 화면 | 내용 |
| --- | --- |
| 참가자 (휴대폰) | 접속 정보 입력, 문제와 선택지, 내 점수 |
| MC 조작 화면 | 시작·다음 버튼, 접속자 수 |
| 대형 화면 | 문제, 현재 팀 점수, 개인 TOP 5 |

**문제 구성**: 8문제 중 2~3개는 "우리의 다수는 무엇을 골랐을까?"를 맞히는 문제로 낸다. 답은 사전 설문 결과를 쓴다. 나머지는 회사·동료·PO 체제 문제로 낸다.

**안정성**

- 와이파이와 LTE/5G로 모두 접속할 수 있어야 한다.
- 재접속해도 점수가 유지되어야 한다.
- 문제 표시부터 제출까지의 시간을 재서 통신 속도 차이를 줄인다.
- 장애가 나면 **다수결 예측**(상대팀 다수의 선택 맞히기)으로 바꾼다. 예측은 비공개로 먼저 제출한 뒤 앉기/서기로 동시에 투표한다.
